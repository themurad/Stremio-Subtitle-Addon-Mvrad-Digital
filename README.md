# Altyazıları buraya atın

`.srt` faylını bu qovluğa yükləyin — vəssalam.

**Add file → Upload files** → faylı sürüşdürün → **Commit changes**

## Faylın adı

Adında IMDb nömrəsi olmalıdır (`tt` ilə başlayan nömrə):

```
tt1375666.srt                      film
tt1375666 Inception.srt            film (ad da yaza bilərsiniz)
tt1375666 [BluRay].srt             eyni filmin ikinci variantı
tt0903747 S01E02.srt               serial, 1-ci sezon, 2-ci seriya
tt0903747-1-2.srt                  eyni seriya, qısa yazılışı
```

IMDb nömrəsi filmin IMDb ünvanında var:
`imdb.com/title/`**`tt1375666`**`/`

Nömrəni bilmirsinizsə, sadəcə adı və ilini yazın — sistem özü tapmağa çalışır:

```
Inception 2010.srt
```

## Qəbul olunan formatlar

`.srt` · `.vtt` · `.sub` (MicroDVD)

Faylın kodlaşdırması (encoding) fərqi yoxdur — sistem özü tanıyır və
düzəldir, ona görə **ə ğ ı İ ö ş ü ç** hərfləri düzgün görünür.

## Qovluqlar

İstəsəniz qovluqlara ayıra bilərsiniz, məcburi deyil:

```
subtitles/filmlər/tt1375666 Inception.srt
subtitles/seriallar/Breaking Bad/tt0903747 S01E02.srt
```
